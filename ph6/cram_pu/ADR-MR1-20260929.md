# ADR-MR1-20260929 — Commit the original optical measurement

Status: PROPOSED implementation candidate. Class C, requested by Jack on 2026-09-29.
proposed_by: codex-lane2; ratified_by: null.
Scope: primary visible-light camera runner, its Lane-1 writer, and downstream
reference reconciliation. No universal tricorder schema or new optical thresholds.

## Problem and decision

The prior camera path measured a BGR acquisition image but preserved only a lossy
JPEG. Its verdict context was not cryptographically bound to the PASS commit, and
SoSo interpretation could throw before preservation. A JPEG hash cannot prove
what PSEUDO originally measured.

The authoritative measurement object in this candidate is the exact packed
uint8 BGR acquisition array presented to PSEUDO. It is not sensor Bayer/ADC data.
The original driver strides are recorded; the preserved layout is packed C order.
The JPEG is an explicitly derived representation with a separate BLAKE2b-256 hash.

A record cannot contain its future disposition and JPEG hash before adjudication.
Therefore the immutable commitment has two linked stages:

1. **CRAM-0:** Persist original acquisition bytes and `ph6.acquisition_commit.v1` with context,
   original-byte hash, identity, sequence, profile/configuration hash and predecessor.
2. **PSEUDO-M** reads and measures those preserved original bytes; **PSEUDO-A**
   alone decides PASS/DROP. The metrics, input references,
   disposition and encoded-payload hash are sealed in `ph6.measurement_record.v1`.
3. **CRAM-A / CRAM-R:** PASS publishes `ph6.cram_commit.v2`, then its `.blake2b` marker LAST. DROP retains
   its immutable measurement and payload without any PASS marker.
4. **One-way Lane-1 to Lane-2 membrane:** Bounded nonblocking notification follows preservation. Discovery and SoSo
   reconstruction occur in the separate advisory worker.

This is a new namespace. Historical JPEG-only records remain historical and
`LEGACY_UNBOUND`; the implementation does not manufacture their original bytes.

## Architectural lineup and concrete storage mapping
+
+Reality → sensor acquisition → **CRAM-0** → **PSEUDO-M** → **PSEUDO-A** →
+**CRAM-A / CRAM-R** → one-way membrane → **TOK / SoSo / AI → MRAM-S**.
+TOK, SoSo and AI are downstream advisory machinery, not an authority hierarchy.
+
+The new namespace's `acquisitions/*.bin` plus matching committed acquisition JSON
+implement CRAM-0. `camera_metrics` is PSEUDO-M and `camera_disposition` is PSEUDO-A.
+`measurements/*.json` binds both dispositions to their retained acquisition and
+derived JPEG. PASS `cram_*.json` plus final marker implements CRAM-A publication;
+DROP measurement records implement the CRAM-R logical subset, without PASS markers.
+These are explicit semantic mappings, not a claim of separate filesystem mounts.
+Current discovery emits RTs for the committed PASS subset only; DROP remains preserved
+and replayable but DROP-to-TOK modeling is not implemented by this change.
+
+## Canonical bytes and identities

JSON hashing uses UTF-8, sorted keys, compact separators, no ASCII escaping, and
no NaN/Inf. Hash the canonical object with its own hash field omitted. Stored JSON
has a trailing newline which is not included in the object hash. All authoritative
hashes are BLAKE2b with digest_size=32. SHA-256 is package compatibility only.

Measurement identity binds run UUID, sequence, original-byte hash and context hash.
The measurement chain includes PASS and DROP. Motion uses the immediately preceding
measurement, including DROP. The separate CRAM PASS chain links only PASS commits.
The first motion result is zero with explicit `NO_PREDECESSOR`, preserving the
installed decision rule without representing a nonexistent prior observation.

## Known and unknown semantics

Time is host time immediately after camera read, not exposure time. Monotonic time
is a host-process observation, not a cross-reboot global clock. The device path and
backend are locators; physical instrument identity and calibration remain UNKNOWN.
Unreported or ambiguous zero-valued OpenCV controls remain UNKNOWN. Temperature is
host temperature, not calibrated scene radiometry. Disk free bytes are host I/O state.

Brightness, Laplacian variance, motion and entropy are deterministically derived
from the preserved original. Fixed-point scale is 10000, half-even rounding. The
installed brightness 20–235, Laplacian >=15 and motion <=0.40 gates are unchanged.
Entropy is recorded but has no decision gate. AC-3 optical policy ratification is
still open. The profile name identifies this implementation, not a ratified profile.

SoSo brightness labels are interpretations. They exist only in advisory snapshots
after a measurement passes independent source/hash/metric replay checks. A malformed
legacy context becomes INVALID_CONTEXT, never RECOVERED. Legacy context that passes
structural checks is still unbound. When a previously covered source becomes corrupt
or missing, affected advisory snapshots lose their current-valid provenance claim.

## Crash and ownership contract

One Lane-1 publisher holds an exclusive nonblocking flock per evidence namespace.
Each publication is write temporary file, fsync file, rename, fsync parent directory.
Existing final bytes must match exactly and are never overwritten. A complete
prefix and at most one pending acquisition are supported. Startup validates all
existing evidence before extending a recoverable tail. Valid original+context can
be remeasured; valid final PASS can finish marker publication. Raw bytes without
context remain explicitly unresolved. Temporary fragments remain for inspection.

These tests establish process-crash behavior on the installed filesystem, not a
physical power-loss guarantee or storage-controller durability certification.
Hashes are tamper evidence relative to a trusted retained head; they are not a
signature against an attacker able to rewrite the entire store and all anchors.
Existing OS privilege separation remains a separate deployment requirement.

## Compatibility and consequences

Generic synthetic capture disables pre-preservation SoSo but retains its legacy
payload contract. It is not an optical measurement-record implementation. Legacy
CRAMWriter and old stored evidence formats remain readable. Camera departure,
arrival and verdict JSONL files are post-preservation compatibility receipts;
recovery authority comes from the immutable measurement records, not those logs.

Original images increase storage by width*height*3 bytes per acquisition. Routine
Lane-1 work depends on the current/previous frame, not advisory history. Startup
and worker discovery perform full replay. The existing RP-12 TOK append/history
cost is not repaired in this change; it remains downstream. Repeated full worker
scans may be expensive and remain subject to the existing resource cage.

Replay pins OpenCV, NumPy and Python versions and verifies exact JPEG re-encoding.
Different numerical/encoder environments fail closed and need an explicit replay
compatibility decision. No library upgrade is silently interpreted as parity.

## Validation and release boundary

Required evidence: original-before-PSEUDO ordering; independent original/JPEG and
record hashes; exact metric/disposition replay; SoSo exception/stall/crash; malformed
context and identities; JPEG re-encoding and payload/metric tamper; missing parents,
markers and roots; interruption at each publication boundary; actual SIGKILL and
restart; duplicate/no hints; gap-aware discovery; no writes to old evidence.

See the separate change-set evidence directory and report for actual executions.
A test pass is mechanical evidence. Only Jack ratifies the candidate. The existing
production service and source checkout are not migrated by this proposal.
