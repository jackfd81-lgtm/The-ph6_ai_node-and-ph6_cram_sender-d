## Foundational Flow
Reality → Measurement → Validation → Preservation → Modeling → Continuity → Understanding

## Core Principles
- AI-native, but **not AI-authoritative**.
- Soft in. Hard out.
- SoSo organizes deterministically; it does not assert validity.
- Observation vs interpretation separation is mandatory.
- Intake is not authority.
- Preservation before trust.
- Modeling is downstream of measurement, validation, and preservation.
- Stale, bad, conflicting, incomplete, or unverified information must be explicitly labeled as such.
- Status distinctions are enforced: DRAFT, REVIEW, CORRECTION_REQUIRED, STRUCTURE_BASELINE_ACCEPTED_FOR_DRAFT_USE, RATIFIED, ARCHIVED.

## Subsystem Semantics

Integration must occur through explicit adapters, bridges, or interface contracts. Do not flatten subsystem-native semantics into generic modules.
