```text

4. Replayability
5. Chain of custody

8. Export survivability
```

That requires hard constitutional law, not flexible consensus or majority vote.

## 9. AMENDMENT RULE

A CDG amendment requires:

```text
1. Written proposal against this document
2. Doctrine impact check — identify which layers are affected
3. Drift Gate scan — no forbidden field, no authority escalation
4. Test evidence — PASS with real frame data
5. Replay verification — replay parity receipt emitted
6. Version bump — CDG-1.x or CDG-2.0 as appropriate
7. Seal — commit + gate card update
```

Amendments may not:

```text
- Grant Lane 2 any execution authority
- Remove replay as the appeal mechanism
- Remove RSYNC Priority Zero
- Weaken Drift Gate
- Make CRAM mutable by advisory systems
```
