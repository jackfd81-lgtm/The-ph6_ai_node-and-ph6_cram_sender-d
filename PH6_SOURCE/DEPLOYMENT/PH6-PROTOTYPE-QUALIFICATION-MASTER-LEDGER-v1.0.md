## How to read this ledger

- Every row is derived from an artifact this audit actually opened and is cited
  by path. No row was fabricated or interpolated from narrative text.
- `Evidence Grade`: **FILE-VERIFIED** (individual per-record artifacts counted/
  hash-checked directly), **MANIFEST-VERIFIED** (a summary/manifest JSON exists
  and is internally consistent, but per-record artifacts were not individually
  recomputed), **NARRATIVE-ONLY** (a markdown/doc claim with no backing
  artifact found in the repository).
- `Lifecycle State` uses only: DESIGNED, IMPLEMENTED, EXECUTED, VERIFIED,
  CLOSED, RATIFIED — never collapsed. `Result` uses only the vocabulary
  authorized by the audit brief (DEMONSTRATED / OBSERVED / CHARACTERIZED /
  EXECUTED / VERIFIED / PASS_PENDING_REVIEW / CLOSED / RATIFIED / OPEN /
  CONSTRAINED / FAILURE FOUND / INCONCLUSIVE / NOT FOUND / UNRESOLVED /
  REFUTED).

  PSEUDO-A (Lane-1). Nothing in this ledger closes a gap, ratifies a
  campaign, or declares production readiness — those require Jack Disla's
